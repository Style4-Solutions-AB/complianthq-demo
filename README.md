# complianthq-demo

Exempelsajt för CompliantHQ, publicerad på https://demo.complianthq.ai. Företaget på sajten är påhittat.

## Så publicerar du

Allt som pushas till grenen `main` publiceras på demo.complianthq.ai inom någon minut. Det finns inget byggsteg. Filerna visas som de ligger i repot, med `index.html` som startsida.

## Regler

- Ren HTML och CSS. Inget byggverktyg och inget CMS.
- Inga riktiga namn, adresser, telefonnummer eller organisationsnummer.
- Varje sida har `<meta name="robots" content="noindex">`, så att sajten inte hamnar i sökmotorer.
- Sajten har brister med flit, eftersom den används för att visa vad CompliantHQ hittar. Rätta dem inte av misstag.
- Filerna `CNAME` och `.nojekyll` ska ligga kvar. De styr adressen och publiceringen.
- Repot är publikt. Lägg aldrig lösenord, nycklar eller kunduppgifter här.
